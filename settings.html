GAME RULES

DOWN 길게: 게임 토글 · BACK: 연습 복귀 · DOWN: 한영 전환 · DOWN 두 번: 소리 토글. 문장은 시계의 MENU → Game → 문장 가져오기에서 순환하여 가져옵니다.

💾저장한 문장
Checkbox는 삭제 전용입니다. 문장의 수정·삭제·시계로 전송은 해당 문장을 클릭하여 메뉴에서 선택하세요
0 / 254 bytes
최대 UTF-8 254바이트. 한글·영문 등 BMP 문자만 지원합니다. 입력한 문장은 시계로만 전송하며 저장 이력에 추가하지 않습니다.
전송된 문장은 REPLAY에 기억됩니다. 다시 들으려면 double-select-click을 누르세요.

모드별 표에서 이 허용오차를 적용할지 선택합니다.
Secondary · 보조 물리 버튼 (선택 사항)
현재 글자 취소
현재 조합 중인 한 글자와 모르스 입력을 취소합니다. 기본값은 위(UP) 버튼 한 번 클릭입니다.
전체 입력 지우기
시계의 입력 문장과 조합을 모두 지웁니다. 기본값은 위(UP) 버튼 길게 누르기입니다.
